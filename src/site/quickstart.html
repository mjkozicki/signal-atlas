QUICKSTART / GET RUNNING

Your first scan can be synthetic.

Try all three services without a radio, reader, or special permissions. Choose Docker for the demo, or build natively for hardware setup.

RECOMMENDED FOR A FIRST LOOK

Run with Docker

Demo ready

Start Docker Engine/Desktop with Compose, then run:

git clone https://github.com/mjkozicki/signal-atlas.git
cd signal-atlas
docker compose up --build -d --wait

Open http://127.0.0.1:8787. With npm installed, npm run docker also builds and launches the container. Snapshots persist in a named volume. Stop with docker compose down.

FOR LOCAL DEVELOPMENT & HARDWARE

Build from source

Requires Go 1.26.4+, Node 22.12+, and npm.

git clone https://github.com/mjkozicki/signal-atlas.git
cd signal-atlas
npm ci
npm run local -- --demo

Open http://127.0.0.1:8787. The documented build workflow uses macOS or Linux; use WSL on Windows.

Ready for real observations?

The Docker image supports demos and stored-data workflows. Live Wi-Fi capture needs Linux monitor-mode hardware; Bluetooth and NFC need their native providers and compatible devices. Hardware behavior varies by OS, adapter, reader, and tag. Follow the protocol guides before starting a live scan.

This website introduces the project. Scanning and saved observations live in the app you run on your own machine.

From a demo to your own observations

Use npm run local for normal local databases. Import Wi-Fi captures through the dashboard, or install native providers for Bluetooth/NFC. To build without launching, run npm run build.
